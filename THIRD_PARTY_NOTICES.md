# Third-party software

Scribo is built on the following open-source components. Their licences apply to the respective parts.

| Component | Licence | Used for |
|---|---|---|
| [Electron](https://www.electronjs.org/) | MIT | desktop shell |
| [PDF.js](https://mozilla.github.io/pdf.js/) (`pdfjs-dist`) | Apache-2.0 | rendering PDFs, text layer |
| [pdf-lib](https://pdf-lib.js.org/) and `@pdf-lib/fontkit` | MIT | writing annotations into PDFs |
| [perfect-freehand](https://github.com/steveruizok/perfect-freehand) | MIT | pressure-sensitive stroke outlines |
| [Lucide](https://lucide.dev/) | ISC | interface icons |
| [electron-updater](https://www.electron.build/) | MIT | updates from GitHub Releases |
| [Inter](https://rsms.me/inter/) | SIL OFL 1.1 | text tool font |
| [Source Serif 4](https://github.com/adobe-fonts/source-serif) | SIL OFL 1.1 | text tool font |
| [JetBrains Mono](https://www.jetbrains.com/lp/mono/) | SIL OFL 1.1 | text tool font |
| [Caveat](https://github.com/googlefonts/caveat) | SIL OFL 1.1 | text tool font |

The pdf.js text-layer stylesheet (`src/styles/textlayer.css`) is taken from PDF.js, © Mozilla Foundation, Apache-2.0.
